## What I hunt

- **Evasive automation:** bots borrowing browser fingerprints, changing request patterns, and blending into ordinary traffic.
- **Coordinated identities:** timing, repeated behavior, and interaction patterns that connect suspicious accounts.
- **Agent trust failures:** prompt injection, tool poisoning, and boundary crossing in autonomous workflows.

<sub>Observe the behavior. Form a hypothesis. Test it against the evidence.</sub>
